# Just Another Todo Application
A simple todo application that can be run in command line.
Made in C.

# How to build
On the console, just run "make build" in the project directory.

# My Notes
Everyone has been building a Todo application as one of their first projects.
So, I decided to build one of my own in C.

I had to use AI to look up the functions to load the CSV file and parse the data inside.
Aside from that, I wrote everything myself.

Also, the program has very little error checking or input sanitization. So, beware of bugs and crashes.

Use it as a little educational guide on what to do and MORE IMPORTANTLY, what not to do.
